# DarkTrace Intelligence

## Evidence-Driven Dark Web Threat Actor De-anonymization Platform

DarkTrace Intelligence is a cybersecurity investigation platform designed to analyze authorized or privacy-safe dark web threat intelligence and identify potential relationships between anonymous behavioral personas.

The platform combines dark web data ingestion, PostgreSQL storage, NLP-based feature extraction, behavioral clustering, explainable relationship scoring, and REST APIs to support evidence-driven investigation workflows.

> **Important:** The current DarkForums Safe Corpus anonymizes/redacts author identities. The personas and relationship scores generated by this prototype represent analytical similarity signals and do not establish or confirm real-world identities.

---

## Problem Statement

Dark web threat intelligence is often fragmented across forum threads, posts, handles, categories, and other evidence sources. Manually correlating these observations can make it difficult for analysts to identify recurring linguistic, behavioral, temporal, and topical patterns.

DarkTrace Intelligence provides a unified analytical pipeline for organizing this information and generating explainable relationships between anonymous behavioral personas.

Machine Learning Workflow
1. Data Loading

Posts and thread information are imported from:

data/safe_corpus.jsonl

using:

ingestion/darkforums_loader.py
2. Feature Extraction

The analysis pipeline extracts features such as:

Average post length
Average sentence length
Vocabulary size
Punctuation rate
Average word length
Technical-term rate
Posting frequency
Active posting hours
Dominant topic/category

The implementation is located in:

ai/feature_extraction.py
3. Behavioral Clustering

TF-IDF is used to represent post content.

KMeans is then used to identify groups of posts exhibiting similar textual patterns.

The current prototype produces:

5 analytical behavioral personas
4. Persona Feature Storage

The calculated features are stored in:

persona_features
5. Relationship Analysis

Pairs of analytical personas are compared using:

Linguistic similarity
Behavioral similarity
Topic similarity
Temporal similarity

The combined relationship signal is stored in:

persona_relationships

For five analytical personas, the current implementation generates ten pairwise relationships.

Explainable Relationship Analysis

Each relationship contains individual evidence signals rather than relying on a single score.

Example:

Persona A ↔ Persona B

Linguistic similarity    : 0.37
Behavioral similarity    : 0.46
Topic similarity         : 0.59
Temporal similarity      : 0.66
Overall confidence       : 0.48

The system also stores an explanation describing which signals contributed to the relationship.

The confidence value represents an analytical similarity measure. It is not proof of common real-world authorship or identity.

Evidence and Safety

DarkTrace Intelligence is designed around evidence-backed analytical signals.

The system distinguishes between:

Observed evidence
        ↓
Analytical similarity
        ↓
Confidence score
        ↓
Verified identity

These concepts must not be treated as equivalent.

The current DarkForums Safe Corpus contains anonymized/redacted author information. Consequently, the current prototype does not establish real-world identities from the dataset.

Any additional PGP, wallet, infrastructure, cross-platform, or identity-linked evidence used in future demonstrations should be authorized or clearly synthetic and should retain source provenance and confidence information.
